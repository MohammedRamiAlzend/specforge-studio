# Project Charter

## Mission

A full-detail e-commerce storefront: product catalog, shopping cart, checkout with payments, order management, inventory tracking, customer accounts, and admin analytics. Backend is an ASP.NET Core (.NET) REST API with EF Core; frontend is a React (TypeScript) single-page application.

## Objectives

- Deliver a working product per the approved requirements (02-requirements/srs.md).
- Maintain full traceability from requirements to tasks and tests.
- Keep the database as the single source of truth.
## Scope

In scope: the modules and requirements listed in 02-requirements/srs.md. Out of scope decisions are recorded in 01-planning/scope.md and ADRs (08-governance/adrs.md).

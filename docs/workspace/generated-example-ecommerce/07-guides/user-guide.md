# User Guide

## Workflow

1. Create a project (Dashboard → New project).
2. Model workflows, data, architecture, and sequences on the Visual Modeler canvas.
3. Run validation and save the graph.
4. Generate diagrams from the model (Diagrams page or canvas Preview diagram).
5. Generate the Markdown workspace (Docs Export page).
6. Track tasks and approvals; execute task packs with agents.
## Key Concepts

- Models are structured data — you never write Mermaid.
- Every artifact has a stable ID for traceability.
- Approval gates protect final requirements, architecture, and schema.

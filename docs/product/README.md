# Product Documentation — SpecForge Studio

This folder is the product definition for SpecForge Studio (phase 01).

## Reading Order

1. `vision.md` — why the product exists
2. `PRD.md` — what the product is and does (start here if you read one document)
3. `scope.md` — what is included in v1
4. `non-goals.md` — what is explicitly excluded
5. `user-roles.md` — who uses the system
6. `success-metrics.md` — how success is measured
7. `open-questions.md` — unresolved decisions and suggested defaults

## ID Conventions

- PRD-001 product requirements document
- VSN-001 vision
- SCP-001 scope
- NGL-001 non-goals
- ROL-001 user roles
- MET-001 success metrics
- OQ-001… open questions
